# Клініка «Верес»

Сайт приватної клініки на Flask + SQLite.

Сторінки: головна (послуги, лікарі), сторінка лікаря, запис на прийом, адмінка (лікарі і заявки).

Сайт: https://karpushayarik-commits.github.io/clinic-site/ (без адмінки, бо GitHub Pages не запускає Python)

## Запуск
```
pip install -r requirements.txt
python app.py
```
Адмінка: http://127.0.0.1:5000/login/ (admin / admin123)
