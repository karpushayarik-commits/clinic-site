# Клініка «Верес»

Курсовий проєкт з дисципліни «WEB-технології та WEB-дизайн». Сайт приватної клініки: пацієнт може
подивитися послуги й лікарів і записатися на прийом, адміністратор веде список лікарів і обробляє заявки.

## Що вміє сайт

- головна: послуги з цінами і лікарі з фільтром за спеціальністю
- сторінка кожного лікаря: освіта, графік, кнопка запису саме до нього
- форма запису з перевіркою даних у браузері і на сервері
- вхід для адміністратора (пароль зберігається в базі як хеш)
- адмінка: додати, змінити або видалити лікаря, переглянути заявки, позначити оброблені, видалити
- видалення через вікно підтвердження, мобільне меню, сторінки помилок 404 і 500

## Технології

Python 3, Flask, Jinja2, SQLite, HTML5, CSS (Grid, Flexbox), JavaScript без бібліотек.

## База даних

Схема лежить у [schema.sql](schema.sql), таблиці створюються при першому запуску:

- `services` — послуги і ціни
- `doctors` — лікарі, кожен прив'язаний до послуги (`service_id`)
- `appointments` — заявки пацієнтів, прив'язані до лікаря (`doctor_id`)
- `users` — адміністратори, пароль у вигляді хешу (`werkzeug.security`)

Усі запити параметризовані (`?`), тому SQL-ін'єкції не пройдуть.

## Структура

```
app.py           маршрути, робота з БД, перевірка форм
schema.sql       структура бази даних
templates/       шаблони Jinja2 (base.html і сторінки)
static/css/      стилі
static/js/       меню, вікно підтвердження, фільтр, перевірка форми
freeze.py        збирає статичну копію для GitHub Pages
design/          опис макета у Figma
```

## Запуск на своєму комп'ютері

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Відкрити http://127.0.0.1:5000.

## Тестовий доступ до адмінки

Проєкт навчальний, тому для перевірки є тестовий обліковий запис:

- сторінка входу: `/login/`
- логін: `admin`
- пароль: `veres2026`

У базі пароль зберігається тільки у вигляді хешу. Для справжнього сайту пароль треба змінити:
задати змінну `ADMIN_PASS` перед першим запуском (тоді база створиться вже з новим паролем).
