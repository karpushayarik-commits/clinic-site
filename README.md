# Сайт приватної клініки «Верес»

Flask + Jinja2 + SQLite. Макет у Figma, статична версія на GitHub Pages.

## Структура сайту
| Блок | Адреса | Що там |
|---|---|---|
| Головна: Hero | `/` | заголовок, кнопка запису, вільні вікна на сьогодні |
| Головна: Послуги | `/#services` | 6 послуг з цінами (з БД) |
| Головна: Лікарі | `/#doctors` | картки лікарів (з БД), клік відкриває профіль |
| Форма запису | `/appointment/` | ім'я, телефон, лікар, дата, коментар; валідація |
| Сторінка лікаря | `/doctors/<id>/` | опис, освіта, графік, кнопка «Записатися до лікаря» |
| Адмінка | `/admin/` | лікарі: додавання, редагування, видалення; заявки пацієнтів |

## Запуск локально
```bash
python -m venv venv
venv\Scripts\activate        # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python app.py                # http://127.0.0.1:5000
```
Вхід в адмінку: `/login/`, логін `admin`, пароль `admin123` (змінюється змінною `ADMIN_PASS`).

База `clinic.db` створюється автоматично при першому запуску й заповнюється початковими даними.

## Використані теми курсу
- Шаблонізація Jinja2: `base.html` + сторінки
- Форми, GET/POST, валідація, сесії, вхід/вихід
- SQLite: послуги, лікарі та заявки зберігаються в БД
- CRUD: лікарі (створення, редагування, видалення) і заявки (перегляд, зміна статусу, видалення)

## GitHub Pages
GitHub Pages не виконує Python, тому `freeze.py` (Frozen-Flask) збирає статичну версію в `build/`:
головна, форма запису й сторінки всіх лікарів. Форма в статичній версії зберігає заявки в `localStorage`,
адмінка доступна лише в повній версії.

Збірка й публікація виконуються автоматично workflow `.github/workflows/pages.yml` після пушу в `main`.
Локальна перевірка: `python freeze.py`, потім відкрити `build/index.html`.
